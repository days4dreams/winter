# Fonts

Self-hosted, so pages don't depend on Google. All three are free under the
SIL Open Font License 1.1 (https://openfontlicense.org), which allows using
them on a website.

| File | Font | Use |
| --- | --- | --- |
| `baskervville.woff2`, `baskervville-italic.woff2` | Baskervville (weights 400–700) | Headings and body text |
| `dm-sans.woff2` | DM Sans (weights 300–600) | Labels, buttons, form fields |
| `oooh-baby.woff2` | Oooh Baby | Handwritten accents |

These are the Latin character set from Google Fonts (November 2026),
which covers English, accents and curly quotes.
